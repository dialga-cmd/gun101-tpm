## Roadmap

- [x] Linux support (TPM 2.0 via tpm2-pytss)
- [ ] Windows support (native TBS-based backend — not started)
- [ ] macOS support (Secure Enclave-based backend — most Mac hardware has no TPM 2.0 chip, so this would be a different security backend, not a port of the TPM one)

No timelines — just record the intent so it reads as deliberate scoping, not an oversight.
